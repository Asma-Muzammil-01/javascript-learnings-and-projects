# Palindrome Checker

A simple JavaScript web app that checks whether a word or phrase is a palindrome.

## Description
A palindrome is a sequence of characters that reads the same forward and backward, ignoring spaces, punctuation, and capitalization. This project lets users type a value into an input field and click a button to see whether it is a palindrome.

## Features
- Accepts user input from a text field
- Compares the input with its reversed version
- Displays an alert indicating whether the value is a palindrome
- Clears the input after checking

## How it works
1. Enter a word or phrase in the input box.
2. Click the Check button.
3. The app reverses the text and compares it to the original input.
4. A message is shown based on the result.

## Run the project
Open the HTML file in a browser to use the app.
