# Random Quote Generator

A small JavaScript project that displays a random quote from a predefined list. The app avoids repeating the same quote until all quotes have been shown once.

## Features

- Generates a random quote on button click
- Prevents duplicate quotes until the full list has been used
- Simple HTML + JavaScript implementation
- No dependencies required

## Project Files

- `main.html` – page structure and button
- `index.js` – quote list and randomization logic

## How to Run

1. Open `main.html` in a browser.
2. Click the Generate Quote button.
3. A new quote will appear each time you click.

## Example

The app uses a collection of quotes such as:

- "Speak only if it improves upon the silence."
- "The quieter you become, the more you can hear."
- "Silence is a source of great strength."

## Notes

This project is intentionally lightweight and easy to extend. You can add more quotes by editing the `quotes` array in `index.js`.
